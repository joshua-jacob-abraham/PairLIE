
# PairLIE: Low-Light Image Enhancement

A demo implementation of **PairLIE**, a deep-learning method for enhancing low-light images.

This repository includes the pretrained model, an interactive Gradio demo, sample images, and a Google Colab notebook for running the demo with a GPU.

## 1. About the Project

PairLIE learns a low-light image enhancement model from paired low-light instances, without requiring conventional low-light and normal-light image pairs.

The demo lets you compare three outputs:

- **Original:** The uploaded low-light image.
- **Brightness Adjustment:** A traditional brightness adjustment.
- **PairLIE Enhancement:** The output produced by the pretrained PairLIE model.

### Research Paper

*Learning a Simple Low-Light Image Enhancer from Paired Low-Light Instances*

Published at CVPR 2023.

[Read the paper](https://openaccess.thecvf.com/content/CVPR2023/papers/Fu_Learning_a_Simple_Low-Light_Image_Enhancer_From_Paired_Low-Light_Instances_CVPR_2023_paper.pdf)

## 3. Requirements

The demo requires:

- Python
- An NVIDIA GPU
- CUDA-compatible PyTorch
- NumPy
- Pillow
- Gradio

### Tested Environment

The demo was tested with the following environment:

| Component | Version |
|---|---|
| Python | 3.13.16 |
| PyTorch | 2.14.1+cu130 |
| NumPy | 2.4.6 |
| Pillow | 11.3.0 |
| Gradio | 6.31.0 |

Other environments may work with compatible package versions and CUDA configurations.

**CPU-only execution is not supported.** If you do not have access to a compatible NVIDIA GPU, use the Google Colab instructions below.

## 4. Run Locally

### Step 1: Clone the repository

```bash
git clone https://github.com/joshua-jacob-abraham/PairLIE.git
cd PairLIE
```

### Step 2: Install CUDA-enabled PyTorch

Install a PyTorch build compatible with your NVIDIA GPU and CUDA environment.

Use the official PyTorch installation selector:

https://pytorch.org/get-started/locally/

Verify that CUDA is available:

```python
import torch

print("PyTorch:", torch.__version__)
print("CUDA available:", torch.cuda.is_available())

if not torch.cuda.is_available():
    raise RuntimeError("A CUDA-compatible NVIDIA GPU is required.")
```

### Step 3: Install the remaining dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Launch the demo

```bash
python demo/app.py
```

Open the local URL printed in the terminal.

Upload a low-light image, adjust the brightness slider if desired, and click **Enhance Image** to compare the results.

## 5. Run Using Google Colab

You can run the demo without setting up a local Python environment.

1. Open the [PairLIE Demo notebook in Google Colab](https://colab.research.google.com/github/joshua-jacob-abraham/PairLIE/blob/main/PairLIE_Demo.ipynb).
2. Select **Runtime → Change runtime type**.
3. Select a GPU runtime.
4. Run the notebook cells in order.
5. Open the public Gradio URL generated by the notebook.

The notebook clones this repository, installs the demo dependencies, checks GPU availability, and launches the interface.

## 6. Sample Images

## 7. Original Implementation: Training and Evaluation

This repository retains the original implementation files:

- `main.py` — training entry point.
- `dataset.py` and `data.py` — dataset handling.
- `eval.py` — evaluation entry point.
- `net/net.py` — PairLIE network architecture.
- `weights/PairLIE.pth` — pretrained model weights.

The original authors provide their training dataset and results here:

[Original dataset and results](https://drive.google.com/file/d/1gM3QeNDOCzx0m1gpOoQD1TnGv1BELy08/view?usp=sharing)

Detailed instructions for preparing the training dataset and reproducing training are not included in this demo guide.
